## chDB and ClickHouse

The `brikk-chdb-native-*` publications contain native `libchdb` binaries from
[chdb-io/chdb-core](https://github.com/chdb-io/chdb-core), release **v26.9.0**,
using the embedded [ClickHouse](https://github.com/ClickHouse/ClickHouse) engine.
Both projects are Apache-2.0 licensed. The Kotlin binding is written against the
release's supported C ABI; it is not a JDBC driver and does not include code from
the Java binding prototypes reviewed in the design document.

Each `chdb-native.properties` records the upstream release URL, platform,
archive checksum, and resource path. The packaging plugin verifies the archive
and records the extracted library checksum. See
[the native packaging design](docs/design/brikk-chdb.md) for provenance and refresh
requirements. Retain upstream notices when updating/repackaging native artifacts.
